# MoeMusic Bilibili Source

适用于 [MoeMusic](https://github.com/lolicode-org/MoeMusic) 的哔哩哔哩插件，用于在 MoeMusic 内播放B站公开视频中的音频

### 功能

支持：搜索，链接解析，播放公开视频的音频

**不支持**：登录，解析付费视频（及其他任意需要绕过版权保护措施的功能），直播，[音频区](https://www.bilibili.com/audio/home)

### 安装

下载 [Release](https://github.com/lolicode-org/MoeMusic-bilibili-source/releases/) 中**不带** `-sources` 后缀的 jar，放入`config/moemusic/plugins/`

### 许可证

AGPL-v3

---

A Bilibili plugin for [MoeMusic](https://github.com/lolicode-org/MoeMusic), used to play audio from public Bilibili videos within MoeMusic.

### Features

Supported: Search, link parsing, playing audio from public videos.

**Not supported**: Login, parsing paid videos (and any other features requiring bypassing copyright protection measures), live streams, [Audio Section](https://www.bilibili.com/audio/home).

### Installation

Download the jar **without** the `-sources` suffix from [Releases](https://github.com/lolicode-org/MoeMusic-bilibili-source/releases/), and place it into `config/moemusic/plugins/`.
